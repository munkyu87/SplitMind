# SplitMind 기획

2026-10-22. 익명 밸런스 게임. 슬로건은 `Life = Choices`.

로그인하고, 곤란한 선택지 중 하나를 고르고, 사람들이 어떻게 갈렸는지 본다. 제안은 관리자 승인 뒤에만 공개된다. 질문 목록, 결과, 댓글에는 소셜 이름과 이메일을 보여 주지 않는다.

확정 시안은 `docs/screens`이다. 구현은 그 화면을 따른다.

## 이번 버전에서 하지 않는 것

- 19금 카테고리, 성인 확인, 본인인증. 데이터와 API 가드는 남겨 두고 앱은 그리지 않는다. 카카오·네이버·구글 로그인은 계정을 식별할 뿐 나이를 증명하지 않는다. 본인인증 업체가 정해지기 전에는 19금을 열지 않는다.
- 소셜 네이티브 SDK. 카카오·네이버·구글 앱 키가 생기기 전에는 `POST /v1/auth/dev`를 쓴다. 로그인 버튼을 누르면 이용약관과 개인정보 처리에 동의한 것으로 보고, 처음 로그인 시각을 `users.terms_agreed_at`에 남긴다.
- 질문 신고, 제안 수정·철회·재제출, 댓글 수정. 질문 선택과 결과에는 `이 질문 비공개`를 두지 않는다.
- 비로그인 열람, 공유, 푸시. 계정 탈퇴는 마이에서 한다. 댓글을 지우고 세션을 끊는다. 투표 수는 남긴다. 같은 소셜 계정으로 다시 들어오면 새 사용자다.

## 규칙

| 항목 | 기준 |
| --- | --- |
| 입장 | 로그인 후에만 목록을 연다 |
| 선택지 | 2~4개. 서버 번호는 0부터. 투표 화면에는 번호를 쓰지 않고 문장만 보여 준다. 제안 폼의 칸 순서는 1부터 보여도 된다 |
| 질문 사진 | 제안에서 질문에 사진 하나를 올릴 수 있다. jpg, png, webp, 5MB 이하. `POST /v1/media`에 저장하고, 승인하면 그 주소를 질문에 복사한다. 선택지에는 사진을 두지 않는다 |
| 투표 | 질문당 1회. 제출 전 확인. 제출 후 변경 없음. 중복이면 `409 ALREADY_ANSWERED` |
| 스포일러 | 투표 전에는 비율, 댓글, 별점을 보여 주지 않는다. 미참여 조회의 결과·댓글·별점은 `403 NOT_ANSWERED` |
| 이미 참여한 질문 | 이름표 줄 오른쪽에 배경 없는 체크. 누르면 결과로 바로 연다. 카드 오른쪽 끝은 화살표 |
| 카테고리 | 질문당 1개. 앱 칩은 전체, 연애, 우정, 직장, 일상, 도덕, 사회. 필터 값은 slug |
| 정렬 | 최신순, 많은순(참여가 많은 순), 별점 높은 순, 밸런스 순. 동점은 공개 시각이 늦은 질문 |
| 참여 여부 | 정렬 오른쪽의 참여·미참여. 하나만 켜진다. 참여는 내가 고른 질문, 미참여는 아직 안 고른 질문. 카테고리·정렬과 함께 적용된다 |
| 목록 더 보기 | 한 번에 20개. 스크롤이 끝에 닿으면 다음 20개를 이어 붙인다 |
| 밸런스 순 | 선택 비율이 균등에 가까울수록 위. 응답 30건 미만은 제외 |
| 별점 순 | 별점 5개 미만은 제외 |
| 검색 | 제목 부분 일치. 100자 |
| 별점 | 투표한 뒤. 1~5를 한 개 단위로 고른다. 목록의 평균만 소수로 보여 준다. 사용자·질문당 1개, 수정 가능 |
| 댓글 | 투표한 뒤, 질문 단위, 즉시 공개. 본문 500자. 선택지 문장을 다는 것은 선택. 좋아요, 신고. 삭제하면 목록에서 빠진다 |
| 닉네임 | 가입하면 형용사와 동물 조합을 붙인다. 마이의 수정에서만 고친다. 2~10자. 이미 있는 이름은 쓸 수 없다. 댓글에 이 이름을 보여 준다 |
| 공개 | 질문은 승인 후. 댓글은 즉시. 목록에는 `published`만 |
| 제안 | 제목 50자, 배경 설명은 선택 500자, 선택지 2~4개·각 255자, 카테고리 하나, 사진 한 장 선택. 3개 이상이면 칸 오른쪽 ×로 뺀다. 2개는 남긴다. 4개면 추가가 잠긴다. 상태는 대기·승인·거절. 거절 사유 500자 |
| 신고 | 댓글 오른쪽 깃발. 이유를 고르거나 500자 안으로 직접 적는다. 고른 줄은 보라색으로 남고 저장된다. 그 댓글은 신고함으로 남는다. 신고함을 누르면 적은 이유와 함께 그 신고를 취소할 수 있다. 댓글당 사용자 1회. 관리자는 최근 100건을 보고 댓글을 지운다 |
| 관리자 | `users.is_admin`. 별도 앱이 아니라 마이페이지 입구. DB에서 켠 뒤에는 다시 로그인해야 토큰에 반영된다 |
| 글자 수 | 목록 `limit` 기본 20, 최대 50. AI 프롬프트 4000자 |

목록 커서는 오프셋이다. 보다가 새 질문이 올라오면 페이지가 겹치거나 빠질 수 있다. 이번 버전의 한계로 둔다.

## 화면

확정 시안은 2026-10-22 이미지 세트다. 배경은 따뜻한 흰색 `#FBF7F4`이고, 귀퉁이에 연보라와 분홍 면이 있다. 로고는 세로 알약 둘(연보라, 분홍)과 `SplitMind`, 슬로건 `Life = Choices`이다. 본문은 검정 `#1A1A1A`. 보내기, 지금 만들기 같은 주요 버튼은 노란 바탕에 검정 글자. 소셜 버튼은 카카오 노랑, 네이버 초록, 구글 흰 바탕이다. 첫 구현은 이 라이트 한 장이다. 코드에 있는 dark와 star는 같은 배치를 나중에 뒤집는 테마로 둔다.

선택지 카드는 파스텔로 채운다. 첫 장은 카테고리 색이고, 다음은 분홍, 크림, 연두 순이다. 왼쪽 띠는 조금 진하다. 글자는 검정이고, 오른쪽에 이동 화살표를 둔다. 사진은 질문당 하나다. 질문 선택은 한 스크롤이다. 배경 설명이 있으면 제목 아래에 두고 자르지 않는다. 사진은 그다음이고, 선택지는 그 아래다. 설명으로 가는 별도 버튼은 없다. 둘 중 없는 칸은 그리지 않는다. 사진은 비율을 유지한 채 조금 작게 둔다. 선택지는 그 아래에 붙인다. 양옆 색 칸은 두지 않고, 모서리는 살짝 둥글게 한다. 잘라 내지 않는다. 선택지가 둘이나 셋이면 세로로 쌓는다. 넷이면 문장이 길어도 두 줄의 두 칸이다. 사진이 없으면 그 칸을 두지 않는다. 목록, 로그인, 마이, 관리의 큰 면은 파스텔로 칠하지 않는다. 그 화면의 카테고리 색은 이름표와 칩에 둔다. 질문 목록 카드는 흰 바탕에 옅은 그림자로 배경과 가른다.

시안에 있어도 그대로 옮기지 않는 것.

- 제안 제목은 50자다. 배경 설명은 선택이고 500자다.
- AI 프롬프트는 4000자. 시안의 500은 예시이다.
- 선택지는 문장 하나다. 승인 카드의 부연 문장과 "이 상황에서 당신의 선택은?"은 그리지 않는다.
- 댓글은 최신순이다. 시안의 추천순은 쓰지 않는다. 답글은 댓글 아래 한 단계다. 답글에 다시 답글을 달아도 같은 깊이에 붙는다.
- 북마크와 선택지 부연 설명은 그리지 않는다.
- 결과의 공유 아이콘은 이번 버전에 없다.
- 제안은 탭 루트라 시안 좌상단의 뒤로가기를 두지 않는다.
- 마이의 응원 문과 사람 아이콘은 장식이다. 이메일은 저장하지 않는다. 닉네임은 마이와 댓글에 보인다. 소셜 이름은 쓰지 않는다.

참여 기록은 마이의 참여한 질문을 눌렀을 때 연다. 고른 문장 왼쪽에 체크를 두고, 날짜 왼쪽에 달력을 둔다. 카드를 누르면 결과로 가고, 뒤로 가면 참여 기록으로 돌아온다. `GET /v1/me/answers`는 `choice`에 그 문장을 담는다.

결과 막대는 득표순으로 다시 정렬하지 않는다. 고를 때 본 위아래 순서를 결과에서도 유지한다. 비율은 정수 퍼센트다.

### 공급과 관리자

제안 탭에서 제목, 선택 배경 설명, 선택지, 카테고리 하나를 내보낸다. 관리자만 대기열에서 승인하거나 거절 사유를 남긴다. 승인된 순간 공개 질문으로 복사된다. 기본 시드는 16개다. 배경 설명이 긴 질문과 선택지 3·4개 질문을 더 넣어 두었다. 거절에는 공개 질문이 생기지 않으므로 검수 로그는 제안 id를 기준으로 남긴다.

AI는 설정한 주기(수동, 매일, 매주)에 초안을 대기열에 넣거나, 관리자가 즉시 한 건을 생성한다. 바로 공개하지 않는다. `OPENAI_API_KEY`가 없으면 생성은 거절된다. 모델은 `OPENAI_MODEL` 또는 `gpt-4o-mini`. 카테고리를 못 고르면 일상으로 둔다. 19금 slug는 후보에서 뺀다. 주기 실행은 API 프로세스 한 대 기준이다. 관리자 계정이 없거나 키가 없으면 그 회차는 건너뛴다.

## 저장소

npm workspaces.

| 경로 | 역할 |
| --- | --- |
| `apps/mobile` | React Native 0.80. 화면, 테마, 내비게이션 |
| `apps/api` | NestJS, Prisma, 모듈별 라우트 |
| `packages/contract` | zod 스키마. 앱과 API가 같이 쓴다 |
| `docker-compose.yml` | PostgreSQL 16. 호스트 포트 5434 |
| `apps/api/prisma` | 스키마, 마이그레이션, 시드 |

로컬 5432, 5433은 다른 Postgres가 쓰고 있어서 SplitMind는 5434를 쓴다.

모바일의 서버 상태는 TanStack Query, 세션은 Auth 컨텍스트와 MMKV다. 유지할 것: 로그인 화면 골격, light / dark / star, 약관 WebView, MMKV 키 `theme-mode`, `access-token`, `refresh-token`. Redux 로그인 플래그는 세션 컨텍스트로 바꾸면서 제거한다.

접근 토큰은 15분, 리프레시는 30일이다. 리프레시 원문은 저장하지 않고 SHA-256 해시만 `sessions`에 둔다. 갱신하면 그 리프레시 세션만 폐기한다. 다른 기기는 로그인 상태로 남는다.

## API

접두사는 `/v1`. 인증이 필요한 요청은 `Authorization: Bearer`. 오류 본문은 `{ code, message }`. 헬스와 인증 발급·갱신·로그아웃만 비로그인이다.

### 인증

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| POST | `/v1/auth/social` | `provider`, 제공자 토큰. 카카오·네이버는 액세스 토큰, 구글은 id 토큰 |
| POST | `/v1/auth/dev` | `ALLOW_DEV_LOGIN=true`일 때만. SDK 없이 세션 발급 |
| POST | `/v1/auth/refresh` | 리프레시 회전 |
| POST | `/v1/auth/logout` | 현재 리프레시 세션 폐기 |
| GET | `/v1/health` | 인증 없음 |

응답 사용자는 `id`, `provider`, `isAdmin`, `isAdult`만 내려준다. 이번 앱은 `isAdult`를 화면에 쓰지 않는다.

### 질문

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/v1/categories` | 성인이 아니면 19금 제외. 앱은 19금 칩을 그리지 않는다 |
| GET | `/v1/questions` | `cursor`, `category`(slug), `sort=latest\|popular\|rating\|balance`, `q`, `limit`, `answered=true`, `unanswered=true` |
| GET | `/v1/questions/:id` | 본문, 선택지, 내 응답. 비율 없음 |
| POST | `/v1/questions/:id/answers` | `{ choiceIndex }` 1회. 성공하면 결과 본문 |
| GET | `/v1/questions/:id/results` | 참여한 사용자만. count, ratio, total, myChoiceIndex, myRating |
| PUT | `/v1/questions/:id/rating` | 참여한 사용자만. `{ rating }` 0.5~5.0 |

### 댓글

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| GET | `/v1/questions/:id/comments` | 참여한 사용자만. 최신순. 닉네임, 좋아요 수, 내가 눌렀는지 |
| POST | `/v1/questions/:id/comments` | 참여한 사용자만. `content`, 선택적 `choiceIndex`, 선택적 `parentId`. 답글의 답글은 원래 댓글에 붙는다 |

### 제안과 나

앱의 내 제안은 `GET /v1/me/suggestions`만 쓴다.

| 메서드 | 경로 | 설명 |
| --- | --- | --- |
| POST | `/v1/suggestions` | `title` 50자, `categoryId`, `choices` 2~4. 배경 설명 `description`과 질문 사진 `imageUrl`은 선택 |
| POST | `/v1/media` | 이미지 파일. 응답은 `{ path }` |
| GET | `/v1/me/suggestions` | 내 제안 |
| DELETE | `/v1/me` | 계정 탈퇴. 댓글 삭제, 세션 폐기. 투표 수는 유지 |
| GET | `/v1/me` | 현재 사용자. 닉네임, 로그인 수단, 가입일 |
| PATCH | `/v1/me` | `{ nickname }` 2~10자. 이미 쓰는 이름이면 거절 |
| GET | `/v1/me/answers` | 내가 답한 공개 질문. 선택지 문구 포함 |
| POST | `/v1/me/adult` | 이후용. 이번 앱은 호출하지 않는다 |

| GET | `/v1/admin/reports` | 최근 신고 100건 |

## 데이터

공개 식별자는 uuid. 안 쓰는 테이블은 없다.

| 테이블 | 핵심 |
| --- | --- |
| `users` | provider + provider_id 유일. nickname도 유일. 가입하면 형용사와 동물을 붙이고, 댓글에 그 이름을 보여 준다. is_admin, is_adult. terms_agreed_at은 첫 로그인. deleted_at이 있으면 그 계정은 끝이고 nickname은 비운다 |
| `sessions` | refresh 해시, 만료, 폐기 |
| `categories` | slug, requires_adult, sort_order. 19금 행은 유지 |
| `questions` | source는 seed, user, ai. status는 published, archived. 목록과 상세는 published만 |
| `questions` | description은 배경 설명. 없으면 그 칸을 그리지 않는다. image_url은 질문 사진 하나. 없으면 그 칸을 그리지 않는다 |
| `question_choices` | question_id + choice_index 유일 |
| `question_category_map` | (question_id, category_id) 복합 키. 이번 버전은 질문당 1행 |
| `question_ratings` | 질문·사용자당 하나. DECIMAL(2,1) |
| `user_answers` | 질문·사용자당 하나 |
| `comments` | choice_index 선택. parent_id가 있으면 답글. deleted_at |
| `comment_likes` | 댓글·사용자당 하나 |
| `comment_reports` | 댓글·사용자당 하나 |
| `suggested_questions` | choices는 JSON. origin은 user, ai. status는 pending, approved, rejected. 승인 시 question_id |
| `question_review_logs` | suggestion 기준 승인·거절 |
| `ai_generation_settings` | id=1 한 행. cadence는 manual, daily, weekly |
